# Query the Atlas with SQL
<!-- audience: admin -->

The **SQL query** page lets you ask questions of your atlas's data — counts,
lengths, lists — without downloading anything.

1. Open the SQL query page from the console's **Maps** list.
2. The **Available Tables** list shows each layer you can query.
3. Either:
   - type a question in plain English under **Generate SQL from natural
     language** (e.g. *How many roads are there by street type?*) and click
     **Generate SQL**, or
   - write SQL yourself in the query box.
4. Click **Execute Query**. Results appear below.

Queries only read data — they can't change your atlas.
