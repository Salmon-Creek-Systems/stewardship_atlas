# Interactive Web Map Help

## Basic Navigation
- **click/drag** to move map
- **scroll** to zoom
- **Ctrl/⌘+click** (desktop) or **long press** (mobile) to share a pin at that spot

## Layer Management
- **control layer visibility** in the Visibility box
- **select basemap** with the dropdown at the top of the Visibility box (choose **None** to hide it)

## Location Sharing
- **Share** shares the current view; **Ctrl/⌘+click** on the map shares a pin at that spot
- Both open a pop-up where you pick the link type, then **Copy to clipboard**:
  - Internal map link (default) — opens this map with the same view and layers
  - Google Maps link
  - JSON coordinates
- **Go to…** opens a pop-up: paste coordinates or a Google Maps link and click **Go to**
