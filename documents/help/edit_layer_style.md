# Change a Layer's Style
<!-- audience: admin -->

Open **Alter → Edit Style…** on a layer to change how it looks.

You can change:

- **Colour**, **opacity**, and for areas the **outline colour**
- **Width** — line width, dot size, or icon size
- **Icon** for point layers
- **Labels** — on or off, and which property to label from
- **Colour by property** — shade features by a numeric property
- **Visible by default** — whether it's showing when the map opens
- **Polygon shape** for area layers — *as drawn*, or squared up (runbook
  regions use *square*)

Click **Save**. The web map and edit pages are updated straight away. Printed
maps keep the old style until they're [built](build_outputs.md) again.

A layer's name can't be changed. As with [adding a layer](add_layer.md), let SCS
know about style changes so they're kept permanently.
