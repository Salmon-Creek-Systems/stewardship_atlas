# Delete a Layer
<!-- audience: admin -->

1. Open **Dataset → Delete Layer…** on the layer.
2. The dialog lists everything that refers to the layer and will be cleaned up —
   the maps that show it, edit pages, and so on.
3. Type the layer's name to confirm, and click **Delete**.

## When a layer can't be deleted

If something else is *built from* the layer — another layer derived from it,
mileage markers that depend on it, the layer emailed photos go into — the dialog
says so and won't delete it. Remove or change that dependency first.

## Getting it back

The layer's data isn't destroyed: it's moved to an archive alongside the atlas.
Ask SCS if you need it restored. Let SCS know after deleting a layer so the
change is kept with your atlas's permanent settings.

To empty a layer but keep it, use **Dataset → Clear Layer** instead.
