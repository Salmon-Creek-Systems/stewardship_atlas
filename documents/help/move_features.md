# Move Features to Another Layer
<!-- audience: admin -->

Features sometimes land in the wrong layer — a photo emailed into a catch-all
layer that really shows a water tank, say. You can move them, properties and
all, into the right one.

1. In the Admin Console, open **Alter → Edit** on the layer the features are in
   now.
2. Draw an area around them. The selected features are highlighted.
3. Click **Move to Layer** and choose where they should go. Only layers of the
   same kind (points, lines or areas) are offered.
4. The prompt shows how many features will move. Confirm.

Both layers are updated straight away.
