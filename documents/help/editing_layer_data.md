# Edit Existing Features
<!-- audience: admin -->

Use **Edit** to change the properties of features that are already on the map,
to delete them, or to move them to another layer. To change a feature's *shape*,
use [Reshape](reshape_feature.md).

## Select the features

1. In the Admin Console, find the layer and open **Alter → Edit**.
2. Draw an area around the feature(s) you want to work on.

The features your area touches are **highlighted** on the map, and their current
properties are listed in tabs below the form — so you can check exactly what
you've selected before changing anything.

## Change properties

1. Fill in only the fields you want to change. **Blank fields keep their
   existing values.**
2. Click **Save**. Every selected feature gets the new values.

## Delete features

1. Select the features as above.
2. Click **Delete Features in Area**. The prompt tells you how many will be
   deleted.
3. Confirm.

Deleting can't be undone from the edit map. If you delete something by mistake,
your atlas administrator can recover it from an earlier published version.

## Move features to another layer

See [Move Features to Another Layer](move_features.md).

## Many changes at once

For bulk changes — fixing a typo across many features, filling in a column —
the [spreadsheet workflow](spreadsheet_workflow.md) is usually faster.
