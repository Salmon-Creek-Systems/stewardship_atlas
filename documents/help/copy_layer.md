# Copy a Layer
<!-- audience: admin -->

**Dataset → Copy Layer…** makes a new layer that starts as an exact copy of an
existing one — its data, its styling, and the steps that build it. It's useful
for trying out changes without touching the original.

1. Open **Dataset → Copy Layer…** on the layer.
2. Enter a name for the new layer (lowercase letters, numbers and underscores).

The copy appears on the same maps as the original. From then on the two layers
are independent: editing one doesn't change the other.

Let SCS know about new layers so they're kept with your atlas's permanent
settings.
