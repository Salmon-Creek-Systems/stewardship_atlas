# Draw New Features
<!-- audience: admin -->

Use **Draw** to add new points, lines or areas to a layer. (To change features
that are already there, use [Edit](editing_layer_data.md) or
[Reshape](reshape_feature.md) instead — Edit treats what you draw as a
*selection*, not as a new feature.)

1. In the Admin Console, find the layer and open **Alter → Draw**.
2. The edit map opens for that layer. Zoom to where you want to work, or paste a
   location into **Go to location**.
3. Draw your features (see below).
4. Fill in the properties in the panel at the top right — for example a name.
5. Click **Save**. **Reset** clears everything drawn since the last save.

Everything you draw before one Save gets the same properties, so save between
features that need different names.

## Drawing lines (roads, creeks, trails)

- Click to start, then click at each bend.
- Click the last point again to finish the line.
- Zoom in if you need bends close together — a very short move can end the line.

## Drawing areas

- Click around the outline and click the first point to close it.
- Areas can't have holes.
- Press **Escape** to stop drawing.

## Drawing points

Click each spot. All points drawn before a Save share the same properties.

## After saving

The change is applied straight away and shows up on the web map. Printed maps
are only updated when they're [built](build_outputs.md).
