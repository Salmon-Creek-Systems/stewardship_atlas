# Comment on a Feature
<!-- audience: user -->

Some layers let you leave comments on individual features — a note on a
hydrant, a question about a turnout. Features that already have comments show
a small speech-bubble badge.

1. Click the feature on the web map.
2. Read the existing comments in the pop-up.
3. Type your comment, add your name, and click **Submit**.

Comments are saved to the atlas and anyone viewing the map can read them, so
don't post anything private.

Whether a layer takes comments is set by your atlas administrator.
