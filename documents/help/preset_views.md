# Preset Views
<!-- audience: user -->

Atlases that are divided into named areas — runbook pages, zones, preserves —
have a **Preset Views** list at the top of the web map's right-hand panel.

Pick an area from the list and the map jumps to it, with the layers that make
sense for that area turned on. From there you can zoom, change layers and
[share the view](share_location.md) as usual.

## From the printed runbook

Each page of the PDF runbook links to the same area on the live web map, so you
can go from a printed or downloaded page straight to the current map.

If your atlas has no named areas, the list doesn't appear.
